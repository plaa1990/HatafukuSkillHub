# SkillHub Studio (v12)
แอปวาดรูปเต็มระบบ (PWA) ไม่มีบทเรียนแล้ว: หน้าแรก = แกลเลอรีผืนผ้า, สตูดิโอ = ตัววาด

## อัปขึ้น GitHub Pages
อัปโหลดทุกไฟล์ในโฟลเดอร์นี้ไปที่ root ของ repo (index.html ต้องอยู่บนสุด) และลบไฟล์เก่า (lessons.html) ออกถ้ามี
ถ้าแก้ไฟล์ ให้เปลี่ยนเลขเวอร์ชัน V ใน sw.js เพื่อให้เครื่องผู้ใช้โหลดของใหม่

## ข้อมูล
ภาพวาดเก็บใน IndexedDB ชื่อ `sh4` ของเบราว์เซอร์ (ชื่อเดิม ภาพจากเวอร์ชันก่อนจึงยังอยู่)
สำรองด้วยปุ่ม 📁 ในสตูดิโอ

## ของใหม่ใน v12
- แกลเลอรีผืนผ้า (เปิด/สร้าง/เปลี่ยนชื่อ/ทำสำเนา/ลบ)
- แปรง 3D 🧊: **หลอด 3D (มัน) และหลอดนุ่ม (ด้าน)** แบบ ibisPaint/Procreate (คำนวณแสงเงาจากทรงหลอดจริง มีไฮไลต์ แสงสะท้อน เงาตกพื้น), เจลนูน, ลูกปัด, สีน้ำมันหนา, ดินน้ำมัน, โครเมียม (เลือกทิศแสงได้)
- ตั้งค่าแปรงรายตัว (ปุ่ม 🎚 ตั้งแปรง หรือแตะแปรงที่เลือกอยู่ซ้ำ): ขนาด ความเข้ม ระยะห่าง ความไวแรงกด กระจาย สุ่มขนาด ความเรียบ + ไฮไลต์/เงาของแปรง 3D, มีตัวอย่างเส้น และจำค่าไว้ให้แต่ละแปรง
- ปุ่ม "ทำให้ชั้นนี้นูน" (⟶ เมนู 🎛 แก้ไข → เอฟเฟกต์ 3D)
- ล็อกความโปร่งของชั้น (α), โหมดปากกา (นิ้วไม่วาด), คีย์ลัดบนคอม
- บันทึกอัตโนมัติเมื่อสลับแอป/ออกจากหน้า

## คีย์ลัด
